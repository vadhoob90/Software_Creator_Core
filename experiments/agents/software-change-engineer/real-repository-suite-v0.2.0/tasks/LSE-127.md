# Add granular immutable query-parameter removal

`QueryParams.remove(key)` removes every value for a key. Callers also need an
immutable operation that removes one particular key/value occurrence without
rebuilding the complete query.

## Definition of done

1. Add `QueryParams.remove_value(key, value)` returning a new `QueryParams`.
2. It removes only the first matching occurrence, preserving the order of every
   remaining pair.
3. Keys and values use the class's existing coercion rules.
4. A missing key or value is a no-op that still returns an independent object
   equal to the original.
5. The original object is never mutated; existing `remove`, `set`, `add`, and
   `merge` behaviour is unchanged.
6. Focused tests and relevant repository checks pass.

Do not change encoding rules, equality semantics, or dependency metadata.
