# Experiments

Experiments test PDLC Core concepts with bounded, real examples before Core turns them into supported contracts or infrastructure.

An experiment is not a canonical definition, a supported consumption mode, or evidence of qualification. Its artifacts retain enough context to reproduce the learning and decide whether to promote, reshape, or reject the approach.
